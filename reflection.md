# Week 7 Codex CLI Hands-On

## Project Reflection: 
My approach to using Codex was to make an outline in a word document that 
followed the work flow of the project my team produced for the week 7 team 
deliverable. I started by using the documentation notes from our various steps 
and changing them to command format.

I was happy and relieved to see that like with most AI tools my lack of proper 
spelling did not interfere with Codex interpreting what the command should be 
and executing. 

As to evolution of prompts, I found I added more details and parameters in request 
in subsequent commands.    

The details that Codex provides covering the commands and steps it executes also 
provided me with a way to validate and check the functions performed. The cleaning 
method and how it approached adding a column's median for numeric gaps was 
important to understand how the model predictions can be different from the teams
model. 

I believe that for a project, the prompts should be recorded and then run multiple 
times in sequence in different sessions asking with small variation to see if 
CODEX generates different methods. This could provide better validation of results
vs input and method variations. 

I experienced no real issues with CODEX running commands. It did shut down more 
than once and I struggled to get the session back. The transcript command did
not work which required cutting and pasting the session into a txt editor.
